# Portofolio Saya

Website portofolio pribadi, dibikin pakai Next.js + Tailwind.

## Fitur
- Toggle bahasa ID/EN
- Dark/light mode
- Form kontak (Web3Forms)
- Responsive

## Jalanin

\`\`\`bash
npm install
cp .env.local
\`\`\`

Isi access key Web3Forms kamu di `.env.local`, terus:

\`\`\`bash
npm run dev
\`\`\`

## Ubah isi

Semua teks ada di `data/content.js`.
